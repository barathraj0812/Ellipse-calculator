## 📖 Overview

The ellipse counterpart to the [Hyperbola Calculator](https://hyperbola.pages.dev). It reads standard, translated, general and rotated equations, works out the full geometry in exact and decimal form, and plots it on an interactive graph along with the auxiliary and director circles, area and perimeter.

## ✨ Features

- 🧾 **Equation parser** for standard, translated, general and rotated (xy-term) ellipses, with the circle case handled explicitly
- 🔢 **Exact and decimal results**: fractions and surds alongside configurable-precision decimals
- 📍 **P and Q points**: P lies on the ellipse and is set by its eccentric angle θ, Q is a free point; both are draggable and synced between the graph and the inputs
- 🧰 **JEE tools** built live on the graph: tangents, normals, chords, focal chord, polar, diameters and reflection
- ⭕ **Auxiliary, inner and director circles**
- 📏 **Area** and a **Ramanujan perimeter approximation**
- 🧪 **Laboratory** for experimenting with parameters
- 📝 **Step-by-step derivations** and a searchable formula sheet
- 🏫 **Presentation mode** for classroom use, with mouse, touch and pen input
- 💾 Settings saved with `localStorage`; works with no backend

## 🛠️ Tech Stack
